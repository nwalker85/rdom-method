# Contributing to RDOM

Thank you for your interest in contributing to the **Ravenhelm Development Operations Methodology (RDOM)**.

## Scope of Contributions

RDOM is an authored operational methodology by Nathan Walker, published by Ravenhelm LLC. We welcome:

- Typo and grammar fixes
- Clarifications and edge-case documentation
- Practical implementation examples, tools, and scripts
- Translations and accessibility improvements

Substantive changes to core doctrine, definitions, or the 24 Numbered Principles (`DP-1`..`DP-24`) require an Architecture Decision Record (ADR) and explicit author approval.

## Development Workflow

1. Fork or branch from `main`.
2. Ensure edits conform to `.markdownlint.yml`.
3. Verify chapter structure against `docs/_shared/CONTEXT.md`.
4. Submit a Pull Request with a clear description of the enhancement.
